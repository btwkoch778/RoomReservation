# Room Reservation System

A simple C# Windows Forms application for reserving rooms with customizable time durations. It includes countdown timers, room status updates, and automatic notifications when a reservation ends.

## Features

- Reservation for 6 rooms
- Custom duration in minutes or `mm:ss` format
- Real-time countdown
- Automatic notification when a reservation ends
- Simple and user-friendly interface
